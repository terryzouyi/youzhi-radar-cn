# 游职雷达

面向中国境内互联网与游戏行业的个人求职搜索工作台。用户录入当前经历、目标岗位、城市、薪资和能力关键词后，可以统一查看厂商官网与公开招聘平台职位，并按 100 家重点厂商定向查询。

## 当前能力

- 100 家国内游戏与互联网游戏业务厂商目录。
- 腾讯、网易官方招聘职位。
- 牛客、猎聘公开招聘职位。
- 招聘官网、招聘公众号、校招 / 实习专题与官方内容情报。
- 7 个职业族、36 个可投递主方向，覆盖策划、产品、研发、美术、运营发行、市场商务、质量与洞察。
- 专长按岗位分工、方法 / 技术栈、游戏品类、平台与项目经验分类，相邻岗位自动进入拓展机会。
- 城市硬筛选；工作年限与期望薪资默认软分层，也可主动开启严格模式。
- 统一去重，并按精准匹配、信息待确认、拓展机会三个层级解释推荐结果。
- 按公司定向搜索、职位收藏和设备本地画像。

## 本地开发

需要 Node.js `>=22.13.0` 与 pnpm。

```bash
pnpm install
pnpm run dev
```

常用检查：

```bash
pnpm test
pnpm lint
pnpm run build:pages
```

## 双端发布

- OpenAI Sites：完整动态版本，包含 `/api/jobs` 与 `/api/companies`。
- GitHub Pages：公开静态镜像，展示产品界面和 Top100 厂商库，不直接访问招聘接口；页面会明确引导到动态实时版。

推送到 `main` 后，`.github/workflows/deploy-pages.yml` 会自动构建并更新 GitHub Pages。动态版本仍使用原有 Sites 发布流程，两种构建互不覆盖。

## 数据边界

- 厂商官网职位优先于第三方招聘平台。
- 城市作为明确筛选条件；年限与薪资默认不淘汰岗位，已知差距进入拓展机会，未知信息进入待确认；只有严格模式会排除已知不符项。
- 第三方平台中明确属于餐饮、地产等非目标行业且没有数字业务信号的职位会被剔除。
- 不读取招聘平台登录状态、Cookie 或用户账号数据。
- 不绕过验证码或安全验证。
- 微信公众号没有稳定公开 API：只保存已核验账号名称、公开文章链接或检索词，不读取微信登录状态。
- 示例职位始终明确标记为演示数据。
- 招聘状态、薪资与岗位要求以原始招聘页面为准。
